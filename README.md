# SynaptiX

**Offline-first civic AI for India.** SynaptiX explains laws, turns political and legal jargon
into plain words, and tells people *who actually has the power* to fix their problem
(Sarpanch, MLA or MP), in Indian languages and Indian Sign Language.

> SynaptiX gives **legal information, not legal advice**. It never gives opinions on parties or politicians.

## What it does

| Skill | Example question | How it answers |
|---|---|---|
| **Jargon → plain words** | "What is MPLADS?", "ग्राम सभा क्या है?" | Verified glossary, rewritten simply by a small local model |
| **Who holds the power** | "Who fixes the village road?" | Deterministic lookup over the Constitution's 7th & 11th Schedules: no AI guessing |
| **Legal information** | "My contractor didn't pay minimum wage" | Expert-verified cards + what to do + who to contact (DLSA, labour office) |
| **Upcoming events** | "When is the next Gram Sabha?" | Local events feed, synced by update bundles |

## Architecture

```
INPUT                   CORE                        SKILLS                      OUTPUT
Sign (webcam) ─┐                                 ┌─ jargon        ─┐
Voice (ASR)  ──┼─▶ language detect ─▶ router ──┼─ jurisdiction  ─┼─▶ text
Text         ──┤   (pivot to English)           ├─ legal         ─┤   speech (hard-coded rule TTS,
Photo (OCR)  ──┘                                 └─ events        ─┘   offline; Sarvam optional)
                                                        │
                              verified knowledge base (data/) → retriever → SLM rewrites only
```

- **Facts come only from the verified knowledge base** in `data/`. The small language model (SLM)
  rewrites and simplifies; it never invents laws, numbers or schemes.
- **Runs on a CPU.** The SLM is a 1–2B model, 4-bit GGUF via llama.cpp. Everything works even with no
  model installed (verified text is returned as-is).
- **Sign language:** MediaPipe extracts hand and body keypoints → a **pretrained ISL recognizer
  (263 signs, trained on the INCLUDE dataset, numpy-only)** maps each sign to a word → the SLM turns
  the words into a question → normal pipeline. Signs include POLICE, COURT, LAWYER, HOSPITAL,
  DOCTOR, BANK, MONEY, JOB, SCHOOL, ELECTION, ROAD, OFFICE, PAPER and more.

## Languages

Hindi, English, Bengali, Marathi, Telugu, Tamil, Gujarati, **Kannada**, Malayalam, Odia, Punjabi and
**Marwari**. Run `synaptix languages` for the full list.

## Text to speech: a hard-coded algorithm

Speech is generated by rules, with no model, no recordings and no internet:

1. **Grapheme → phoneme rules** (`synaptix/outputs/g2p.py`). Indian scripts share one Unicode layout,
   so the same offset is the same sound in every script (क, ಕ, க … are all *k*). One table covers all
   eleven Indic scripts; rules add the inherent *a*, handle vowel signs and virama, and drop the final
   *a* in Hindi-belt languages (Hindi, Marwari, Marathi, Punjabi, Gujarati).
2. **Formant synthesis** (`synaptix/outputs/formant.py`). Vowels and voiced sounds are a glottal pulse
   train through three resonators at hard-coded formant frequencies; stops are silence plus a noise
   burst; fricatives are band-limited noise; pitch falls gently across the sentence.

It sounds robotic, but it is tiny, deterministic and works on any CPU offline. For natural voices when
online, `--voice sarvam` uses [Sarvam AI](https://www.sarvam.ai/) Bulbul (needs `SARVAM_API_KEY`) and
falls back to the rule engine if unreachable.

## Quick start

```bash
uv venv -p 3.12 && source .venv/bin/activate
uv pip install -e '.[dev]'

synaptix ask "what is zero hour"
synaptix ask "who is responsible for the national highway"
synaptix ask "ग्राम सभा क्या है"
synaptix ask "my contractor did not pay minimum wage"
synaptix ask "my employer pays less than minimum wage" --district Mysuru   # Karnataka district offices
synaptix location Mysuru            # remember your district
synaptix signs NOTICE SUMMONS COURT MEANING
synaptix ask "ग्राम सभा क्या है" --speak          # writes a WAV with the offline rule TTS
synaptix say "ಗ್ರಾಮ ಸಭೆ" --phonemes

pytest
```

Optional extras:

```bash
uv pip install -e '.[slm]'    # small language model (llama.cpp)
python scripts/download_models.py   # Qwen2.5 1.5B Instruct, 4-bit (~1 GB) -> models/slm.gguf
uv pip install -e '.[sign]'   # sign-language input (MediaPipe Tasks, OpenCV)
synaptix sign-live            # sign to the webcam (pretrained 263-sign model), press q, get the answer
synaptix sign-file clip.mp4 --ask   # recognise signs in a video file
python training/sign/train_include.py --poses Pose_Signs --splits Train_Test_Split   # retrain (needs torch)
# or train on any Kaggle sign-video dataset in Google Colab: notebooks/train_isl_colab.ipynb
export SARVAM_API_KEY=...     # optional natural voices: synaptix ask "..." --speak --voice sarvam
```

## Location (Karnataka districts)

Pass `--district` (for example `Mysuru` or `Mysore`; Kannada names work too) or save a default with
`synaptix location Mysuru`. Legal answers then prefer Karnataka cards and "Talk to" names the district
legal services authority, labour office and so on. `synaptix districts` lists all 31. No phone numbers or
addresses are stored; office contact details are left to be checked at the district office.

## Project layout

```
synaptix/
  core/        types, language detection, router, translation, pipeline
  skills/      jargon, jurisdiction, legal, events
  kb/          knowledge-base loader + CPU retriever
  llm/         llama.cpp wrapper, rewrite guard, prerendered rewrites, evaluation
  outputs/     rule-based TTS (g2p.py + formant.py); optional Sarvam AI voices
  inputs/sign/ MediaPipe keypoints + sign classifier
data/          glossary.yaml, legal_cards.yaml, jurisdiction.yaml, events.json
data/states/   per-state cards, glossary and districts (Karnataka)
training/sign/ record and train the ISL classifier
```

## Status

Early prototype. All knowledge-base entries are marked `review: pending` until a law student and a
native speaker verify them. The Karnataka and district data is new and entirely unverified. Contributions of verified cards and translations are very welcome.
